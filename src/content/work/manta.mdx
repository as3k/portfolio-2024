# MANTA: A Secure and Memorable Passphrase Generator

Manta is a Chrome extension designed to simplify the process of creating secure and memorable passphrases. Born out of my passion for security and a desire to make my own life easier, Manta leverages a custom-built API to generate passphrases that are easier to use, highly secure, and far more memorable compared to traditional hard-to-read strings from password managers.

## Challenge

Traditional password managers generate secure but unmemorable strings of random characters. Users need passwords that are:
- Highly secure against brute force attacks
- Actually memorable for human beings
- Quick and easy to generate
- Accessible without external tools

## Process

I developed Manta from the ground up using Next.js and designed the user interface in Figma to create an intuitive and seamless experience. The extension enables users to quickly generate passphrases that balance security and usability.

### Through this process, I:

- **Designed an engaging and accessible interface** with Figma, ensuring usability for both technical and non-technical users.
- **Packaged my custom-built passphrase API** into a functional Chrome extension, eliminating the need for external tools.
- **Focused on creating a tool that promotes better security practices** by encouraging users to adopt passphrases that are easy to remember yet highly secure.

## Results

Manta currently holds a **5-star rating** in the Chrome Web Store, with a glowing review that says, _"I love this handy lil extension."_ While small, this feedback highlights how Manta has already positively impacted users, further validating my goal of making secure passphrase generation simple and enjoyable.

- **5-star Chrome Web Store Rating** - Validated by actual users
- **Safer Passphrases** - More secure than traditional passwords
- **Simple, Intuitive Design** - Easy for anyone to use
- **Self-initiated project** - Demonstrates initiative and technical range
