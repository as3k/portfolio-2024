# Rebuilding Enterprise Software from WordPress to Supabase

> **Note:** This is an active project I'm currently working on at Member Splash. I'm documenting the process as we go.

## Overview

Member Splash's member-facing platform has grown significantly over the years, but the WordPress-based architecture is showing its limitations. Users struggle with slow page loads, confusing navigation, and a mobile experience that doesn't meet modern expectations.

This project involves redesigning the entire member experience while migrating to a modern stack built on Supabase and React.

## Challenge

The existing platform faces several issues:
- WordPress-based architecture limiting performance and flexibility
- Fragmented user experience across multiple plugins and custom code
- Mobile experience that doesn't meet member expectations
- Complex member workflows that cause confusion and support tickets
- Limited ability to iterate quickly on new features

## Approach

I'm leading the UX strategy and product design for this migration, focusing on:

1. **User research** - Understanding member pain points and needs
2. **Information architecture** - Restructuring the platform for clarity
3. **Design system** - Creating reusable components for consistency
4. **Prototyping** - Testing new flows before development
5. **Development support** - Building out front-end components in React
